# Pocket Arcade

یک اپ آفلاین اندرویدی مینیمال با چهار بازی:
- Snake
- Breakout
- Flappy
- Tic-Tac-Toe

رکورد هر بازی با SharedPreferences ذخیره می‌شود و با بستن برنامه از بین نمی‌رود.

برای ساخت APK:
1. پروژه را در Android Studio باز کنید.
2. Gradle Sync را انجام دهید.
3. Build > Build APK(s) را بزنید.

نام برنامه: Pocket Arcade
